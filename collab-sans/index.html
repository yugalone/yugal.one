I am not a professional developer or traditional type designer. My background is rooted in organizational systems, finance, and building scalable enterprise workflows as a citizen developer (yugal.one). For me, minimalism is not a design preference—it is a way of living and working: stripping away noise so function and clarity become obvious.

That obsession with clarity drew me directly to Rasmus Andersson’s Inter—the undisputed benchmark of modern digital interface typography. Across product interfaces and data dashboards, I wanted that exact mathematical precision and micro-legibility, but with the warmth and understated minimalism that only genuinely rounded terminals can bring.

Rather than drawing outlines by hand, I built this entire font family using Antigravity (Google's agentic AI coding environment). Together, we engineered an algorithmic geometry engine in Python that traversed Inter's 2,548 glyphs contour-by-contour: curving stroke ends with tangent-continuous semicircular caps and preserving proportional inner ink-traps so text remains razor-sharp at 11px–14px UI sizes.
