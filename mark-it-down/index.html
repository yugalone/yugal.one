Mark It Down

A lightweight Chrome extension designed to elevate local and web markdown reading into a distraction-free, beautifully typeset reading experience. Powered by Collab Sans and Inter typography, readable and pageless layouts, markdown and preview toggling, live outline search, and offline KaTeX math & Mermaid diagram rendering.

Core Capabilities
Collab Sans & Inter
Bundled local Collab Sans across 18 styles and Inter variable font, offering warm optical geometry and a 2px interval stepper (12px–20px).
Readable & Pageless Modes
Direct toolbar action and keyboard shortcut (⌃⇧D) to toggle between a focused 700px reading column and an expansive fluid canvas for dense tables and sprawling diagrams.
Markdown & Preview Toggle
Instant one-click switching (⌃⇧X) between beautifully rendered document preview and clean raw Markdown source code without losing scroll position.
Document Spacing
Direct one-click toolbar and keyboard toggle (⌃⇧S) between Compact layout matching native preview density and Comfortable spacious reading layout.
Document Outline & Heading Search
Live sidebar table of contents with real-time heading search, active scroll section highlighting, keyboard shortcut toggle (⌃⇧Z), step buttons, and drag-to-resize panel width (200px–480px).
Collapsible Sections
Interactive chevrons for headings (H1–H6) and nested lists to keep complex, long-form technical documentation structured and navigable.
Offline Viewer & Ingestion
Dedicated offline viewer page (viewer.html) with drag-and-drop file loading, plus right-click Render page with Mark It Down to format any active webpage in-place.
Mathematical Equations
Bundled offline KaTeX engine supporting inline and multi-step display math with automated comment escaping (\%), matrix alignment handling, and table-cell nowrap protection.
Diagrams & Flowcharts
Native client-side rendering for flowcharts, sequence diagrams, and state machines declared in ```mermaid blocks using Collab typography.
Syntax Highlighting & Copy
Minimalist code highlighting across major languages, copyable blocks with language badges, and global ⌃⇧C to copy clean Markdown source directly to clipboard.
Print & PDF Formatting
Engineered print stylesheet with strict page-break rules preventing orphan headings (break-after: avoid) and preserving atomic code blocks, tables, and math derivations.
Document Metadata
Instant inspection drawer showing file name, file path with one-click copy, file size, word count, reading time estimates, heading counts, and total lines.
100% Local & Secure
Zero tracking, zero telemetry, and zero remote scripts. All markdown parsing, math typesetting, and diagram rendering run strictly within the client-side browser sandbox.
