Mail-Merge & Label Studio

Flows

A minimal document and label mail-merge studio for Google Sheets, Google Forms, and Drive CSVs. Connect a data source, design your layout on a live page canvas, and export print-ready PDFs or Markdown files to your device or Google Drive in seconds—with zero Google Docs quotas.

Capabilities & Workflow

Multi-source sync
Load Google Sheets tabs, Google Forms responses, or Google Drive CSV files while keeping exact number, date, and currency formatting.
Record selection
Search rows, filter by column rules or row ranges, and pick specific records to merge—or export the entire dataset.
Data chips
Type / to insert data fields as Text, Image, Link, QR Code, or scannable Barcode, or type _ to insert built-in tokens like dates, record numbers, and UUIDs, // to insert static images, and | to insert tables.
Interactive chips & fallbacks
Click any chip to style it, resize it, or set an empty-field fallback value, or double-click to switch its field type.
Live page canvas
Design on a scaled print canvas with margin guides, inner frame borders, zoom controls, and an interactive record preview.
Starter templates
Start fast with built-in layouts for invoices, business letters, certificates, shipping labels, product SKUs, and barcodes.
Flexible page sizes
Pick standard document and label presets or set custom millimeter dimensions in portrait or landscape orientation.
Quota-free export & Drive save
Download a single combined file or a .zip of individual PDF (.pdf) and Markdown (.md) files, save directly to Google Drive, or print straight from the browser.
Dynamic file naming
Name output files automatically using any merge field or system token from your data source.
Portable Drive projects
Save projects directly to Google Drive or export and import portable .flows.json files.
