Flows

A minimal document and label mail-merge studio for Google Sheets, Google Forms, and Drive CSVs. Connect data via Google Drive Picker, design layouts on a live page canvas with smart data chips, and export print-ready PDFs or Markdown with zero Google Docs quotas.

Now Free ↗
Studio Capabilities
Drive Sync & Data Sources
Connect Google Sheets, Google Forms, or Drive CSVs with native Google Drive Picker integration, multi-column search, row filtering, and automatic cell format preservation.
Smart Chips & Commands
Type / to insert merge fields, _ for system tokens, // for inline images, or | for tables. Configure chips as Text, Dynamic Image, Link, QR Code, or Barcode with fallback values.
Live Scaled Canvas
Visual layout editor with precision margin guides, inner borders, zoom controls, and presets for A4, Letter, Shipping 4×6″, Address Labels, Badges, or custom millimeter dimensions.
Real-Time Record Stepper
Step through records record-by-record directly on canvas to inspect live data bindings and verify edge-case text wrapping before generating output.
1:1 PDF & Quota-Free Export
High-performance rendering engine with embedded TTF font binaries for exact letter-spacing parity. Bypasses Google Docs API quotas to export single combined files or zipped individual PDFs and Markdown.
Drive Save & Dynamic Naming
Save generated files directly to Flows/Files in Google Drive, send straight to physical print, and dynamically format file names using interactive merge field chips (e.g. {{ORDER_ID}}-{{_date}}).
Drive & Local Projects
Auto-saves projects directly to Flows/Projects in Google Drive, with one-click export and import of portable .json project definitions for complete offline backup.
