Flows

A minimal document and label mail-merge studio for Google Sheets, Google Forms, and Drive CSVs. Connect a data source, design your layout on a live page canvas, and export print-ready PDFs or Markdown files in seconds—with zero Google Docs quotas.

Studio Capabilities
Multi-source Sync
Load Google Sheets tabs, Google Forms responses, or Drive CSV files with automatic RFC-4180 delimiter detection while preserving exact number, date, and currency formatting.
Record Selection
Visual row selector with multi-column live search, select all / clear controls, and row checkboxes to merge specific records or process entire datasets in batch.
Trigger Commands
Type / to insert merge fields, _ for system tokens (dates, record counters, UUIDs), // to paste inline images, or | to insert custom tables.
Smart Data Chips
Convert any field into Text, Dynamic Image, Clickable Link, 2D QR Code, or Scannable Code 39 Barcode with custom fallback values for missing records.
Interactive Tables
Insert custom row × column tables with visual grid selection and inline action controls to add, remove, and resize columns without disrupting canvas flow.
Live Page Canvas
Design on a precision-scaled print canvas with visual margin guides, optional inner frame borders, zoom controls (zoom in, zoom out, fit to screen), and full typography styling.
Paper & Label Presets
Choose from A4, Letter, A5, A6, Shipping 4×6″, Address Label 4×2″, Product Label 3×2″, Badge 3×4″, or define custom millimeter dimensions in portrait or landscape.
Real-Time Stepper
Step through records record-by-record directly on canvas to inspect live data bindings and verify edge-case text wrapping before generating files.
Quota-Free Export
Direct rendering engine that bypasses Google Docs API quotas entirely. Download a single combined file or a .zip of individual PDF or Markdown documents.
Direct Print & Drive Save
Send layouts straight to your physical printer (window.print) or save generated files directly to the Flows/Files folder in your personal Google Drive.
Dynamic Naming
Automatically format output file names using any combination of merge fields and system tokens (e.g. {{ORDER_ID}}-Invoice-{{_date}}).
Portable Projects
Auto-save projects directly to Flows/Projects in Google Drive, or export and import lightweight, portable .json project definitions for complete offline backup.
