A minimal document and label mail-merge studio for Google Sheets, Google Forms, and Drive CSVs. Connect a data source, design your layout on a live page canvas, and export print-ready PDFs or Markdown files in seconds—with zero Google Docs quotas.

Studio Capabilities
Multi-source Sync
Load Google Sheets tabs, Google Forms responses, or Drive CSV files while preserving exact number, date, and currency formatting.
Record Selection
Search rows, filter by column rules or row ranges, and pick specific records to merge—or export the entire dataset in batch.
Data Chips
Type / to insert merge fields as Text, Image, Link, QR Code, or scannable Barcode, or type _ for system tokens like dates, record numbers, and UUIDs.
Interactive Chips
Click any chip to style it, resize it, or configure fallback values for missing data fields without breaking layout flow.
Live Page Canvas
Design on a scaled print canvas with margin guides, inner frame borders, zoom controls, and interactive record-by-record preview.
Starter Templates
Start fast with built-in layouts for invoices, business letters, certificates, shipping labels, product SKUs, and barcodes.
Flexible Page Sizes
Pick standard document and label presets or specify custom millimeter dimensions in portrait or landscape orientation.
Quota-Free Export
Download a single combined file or a .zip of individual PDF and Markdown files, save directly to Google Drive, or print straight from the browser.
Dynamic Naming
Name output files automatically using any merge field or system token from your connected dataset.
Portable Projects
Save projects directly to Google Drive or export and import lightweight, portable .flows.json files.
